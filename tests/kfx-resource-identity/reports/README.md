# Reports

Generated, path-free corpus reports are kept outside the public tree. Current
resource-identity and conversion-matrix evidence is summarized by the
[`KFX identity regression README`](../README.md). Oracle comparison reports
belong in the local validation workspace once an independent Calibre KFX Input
installation is available.
Each report must use the stable `KFX-RI-NNN` ID and file hash, and must explain
every visible-resource difference without including source paths, book
metadata, text, or extracted media bytes.
