# Release benchmark seeds

This directory contains only anonymous, repository-safe seeds and workload
recipes. Private books must be supplied through a path outside the repository
and measured into the external validation workspace selected by
`FOLIOFORGE_VALIDATION_ROOT`.

- `micro/`: small deterministic input for index/normalization smoke checks.
- `canonical/`: links to the semantic-equivalence fixtures.
- `representative/`: a manifest template for one sample per adapter.
- `stress/`: generated workload recipes; generated bytes stay external.
